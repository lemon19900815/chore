# IVD基础

IVD领域相关基础知识整理。

## 1. 质控

在 IVD（体外诊断）设备里，**质控数据（QC）收到之后，并不是简单地判断“QC 值是否在范围内”**。比较标准的做法是：

> **QC结果 → 质控品/项目有效性检查 → 计算统计量 → 单规则判断 → 多规则 Westgard 判断 → 在控/失控 → 失控原因分类 → 对患者结果进行影响评估 → 放行/阻断**

典型流程可以理解成下面这样：
```
质控结果到达
    │
    ▼
┌──────────────────┐
│ QC数据有效性检查   │
│ - 项目是否正确     │
│ - QC批号是否正确   │
│ - 水平是否正确     │
│ - 仪器/试剂状态    │
│ - 数据是否重复     │
└────────┬─────────┘
         ▼
┌──────────────────┐
│ 获取QC统计参数     │
│ Mean / SD / CV   │
│ 或实验室自定义参数  │
└────────┬─────────┘
         ▼
┌──────────────────┐
│ 计算 Z-Score      │
│ Z=(X-Mean)/SD    │
└────────┬─────────┘
         ▼
┌────────────────────────┐
│ 单次QC规则判断           │
│ 1₂ / 1₃ / 2₂ / R₄s...  │
└──────────┬─────────────┘
           ▼
      ┌────┴────┐
      │         │
     在控      失控
      │         │
      ▼         ▼
  QC通过       QC拒绝
      │         │
      ▼         ▼
患者结果      阻止/标记患者结果
放行          调查失控原因
```

但实际系统里还有一个非常重要的概念：
**QC判断通常不是针对单个结果孤立判断，而是针对一个“质控运行（QC Run）”进行判断。**

### 1.1 首先确定QC的上下文
例如设备收到：
```
项目：GLU
试剂批号：A123
QC批号：Q202601
QC水平：Level 1
结果：5.82 mmol/L
```

系统首先要找到这个 QC 对应的统计参数：
```
Mean = 5.00
SD   = 0.25
```

然后计算：
```
Z = (5.82 - 5.00) / 0.25
  = 3.28
```

也就是：
```
+3.28 SD
```

这时候就已经触发了非常典型的（`1_3s`）：
```
1₃s
```

### 1.2 QC通常至少有两个浓度
IVD设备比较常见的是：
```
Level 1（低值）
Level 2（高值）
```

例如：

| QC      |  Mean |   SD |  当前结果 |
| ------- | ----: | ---: | ----: |
| Level 1 |  5.00 | 0.25 |  5.10 |
| Level 2 | 10.00 | 0.50 | 10.20 |
系统需要分别计算：
```
L1 Z = (5.10 - 5.00) / 0.25 = +0.4
L2 Z = (10.20 - 10.00) / 0.50 = +0.4
```
这两个结果都正常。

因此：
```
QC Run
 ├── Level 1 → Pass
 └── Level 2 → Pass

最终 Run → In Control
```

这里就开始涉及你之前做的**质控审核/智能审核**里面一个很重要的问题：

> **单个 QC 结果的状态 ≠ 整次 QC Run 的状态 ≠ 项目的 QC 状态。**

### 1.3 Westgard规则

**Westgard 不是一个“所有 IVD 设备强制统一采用”的标准**

**Westgard 规则（Westgard multirule）是一套非常经典、广泛使用的临床实验室内部质量控制（IQC）判定规则体系**，主要用于判断 QC 是否出现随机误差或系统误差。

常见规则包括：

- `1₂s`：警告
- `1₃s`：失控
- `2₂s`：失控
- `R₄s`：失控
- `4₁s`：失控
- `10x`：失控

它的核心作用是：

> **利用 QC 结果相对于 Mean/SD 的位置，以及 QC 历史结果之间的关系，判断分析系统是否处于受控状态。**

但不要把它等同于 ISO/CLSI 标准，可以这样理解：

|类型|作用|
|---|---|
|ISO 15189 等|实验室质量管理/能力认可要求|
|CLSI 文件|实验室质量控制等方面的规范/指南|
|**Westgard Rules**|**具体的 QC 统计判定方法/规则体系**|
|Levey-Jennings 图|QC 数据的统计可视化方法|

质控品靶值&标准差：
```
Mean = 100
SD   = 5

±2SD = 90 ~ 110
```

几种常见规则的解释：

|            规则             | 含义                                      | 质控结果值 | z-score                                                                                                                                                     | 触发方式 | 备注/用途                                |
| :-----------------------: | --------------------------------------- | :---: | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | :--: | ------------------------------------ |
|            1₂s            | 一个 QC 结果超过 ±2SD                         |  111  | Z = (111 - 100) / 5 = +2.2 SD                                                                                                                               |  报警  | 警告，触发进一步检查，**1₂s通常是警告规则，而不是直接判失控**   |
|            1₃s            | 一个 QC 结果超过**同一侧** ±3SD                  |  116  | Z = +3.2 SD                                                                                                                                                 |  失控  | 检测较大的误差                              |
|            2₂s            | 连续两个 QC 结果超过**同一侧** ±2SD                |   /   | Z1 = +2.3 SD<br>Z2 = +2.5 SD                                                                                                                                |  失控  | 检测系统误差                               |
|            R₄s            | 连续两个质控结果之间超过 ±4SD                       |   /   | Z1 = +2.1 SD<br>Z2 = -2.3 SD<br><br>Delta(Z) = Z1-Z2= +4.4 SD                                                                                               |  失控  | 检测随机误差。见下方的特殊说明。                     |
| Nx<br>（N ∈{ 6,8,9,10,12}） | 连续N个结果在 均值 **同一侧**                      |   /   | Z1 = +0.5 SD<br>Z2 = +0.8 SD<br>Z3 = +1.2 SD<br>Z4 = +0.4 SD<br>Z5 = +0.9 SD<br>Z6 = +1.1 SD<br>Z7 = +0.7 SD<br>Z8 = +0.6 SD<br>Z9 = +1.0 SD<br>Z10=+0.8 SD |  失控  | 检测偏移<br>![](img/01.IVD基础-1.png)<br>  |
|            7T             | 连续 7 个结果持续上升或持续下降                       |       | Z1 = +0.1 SD<br>Z2 = +0.2 SD<br>Z3 = +0.3 SD<br>Z4 = +0.4 SD<br>Z5 = +0.5 SD<br>Z6 = +0.6 SD<br>Z7 = +0.7 SD                                                |  失控  | 检测趋势；属于可选规则<br>![](img/01.IVD基础.png) |
|         2 of 3₂s          | 在连续三个相关的质控观测值中，至少两个超过均值**同一侧**的 ±2SD 限值 |       | Z1 = +2.1 SD<br>Z2 = +0.1 SD<br>Z3 = +2.5 SD                                                                                                                |  失控  | 检测系统误差                               |

**关键是“同一批次/同一次运行”**
R₄s 特殊说明：
假设：
```
Run 1:
  L1 = +2.1
  L2 = -0.5

Run 2:
  L1 = +0.8
  L2 = -2.3
```
不能拿：
```
Run 1 L1 = +2.1
Run 2 L2 = -2.3
```
然后说：
```
差值 = 4.4 SD → R_4s
```
这种判断通常是不成立的。
